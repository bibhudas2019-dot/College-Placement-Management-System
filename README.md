College Placement Management System

A desktop-based College Placement Management System developed using Python, CustomTkinter, and MySQL. The system helps manage student records, placement applications, company details, and recruitment activities in one place.

Features

- Student registration and management
- Student dashboard
- Placement application management
- Company and recruitment drive management
- Student placement records
- MySQL database integration
- User-friendly graphical interface using CustomTkinter

Technologies Used

- Python
- CustomTkinter – GUI
- MySQL – Database
- MySQL Connector/Python – Database connectivity

Installation & Setup

1. Clone the Repository

git clone https://github.com/bibhudas2019-dot/College-Placement-Management-System.git
cd College-Placement-Management-System

2. Install Required Libraries

pip install -r requirements.txt

3. Configure MySQL

Make sure MySQL is installed and running on your system.

Create the required database and tables using the SQL files provided in the "database" folder.

Update the database connection details in the project files according to your MySQL configuration.

4. Run the Application

python main.py

How It Works

1. Launch the application using "main.py".
2. Register or manage student information.
3. Add and manage placement/company details.
4. Students can apply for available placement opportunities.
5. Placement records can be maintained through the system.
6. All required information is stored in the MySQL database.

Requirements

- pip
